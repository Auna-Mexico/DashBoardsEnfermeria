# DashBoardsEnfermeria
Para reemplazar un dashboard, entra al dashboard que necesites actualizar, selecciona el lapiz, la opcion de editar, copia el codigo de texto del nuevo dashboard, selecciona commit changes, y en ese apartado introduce la fecha que se realiza la actualizacion, dale a guardar y aproximadamente en 5-10 minutos se vera reflejado el cambio.
